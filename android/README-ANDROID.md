# Greek Wisdom Android

Projeto Android nativo simples que empacota o web app Greek Wisdom em um WebView.

## Gerar APK debug

Com Java JDK 17+ e Android SDK instalados:

```powershell
cd android
.\gradlew.bat assembleDebug
```

O APK sai em:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```
